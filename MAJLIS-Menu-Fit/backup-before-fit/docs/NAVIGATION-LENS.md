# Исправление оптики меню — dom-optics-v3

16.10.2026. Изменяется существующий MAJLIS Mini App. Разделы, кнопки, права и бизнес-API не меняются.

## Причина исправления

На записи с телефона `ScreenRecording_10-16-2026 13-16-00_1.MP4` виден движущийся пустой контур и исчезновение синей плашки. Прежний код считал наличие SVG API/CSS.supports доказательством готовой оптики и скрывал исходный материал. Фактическая отрисовка цепочки feImage/displacement/blend не проверялась. Какая именно стадия не отрисовалась на телефоне, по видео не установлено.

Вновь приложенная запись `Запись экрана 2026-10-15 в 6.15.22 PM.mov` показывает более ранний интерфейс с выбором темы из списка. Для воспроизведения отказа учтена также предоставленная запись с телефона от 16 октября.

## Реализация

- `web/nav-lens.js`: SVG filter/feImage/displacement полностью убраны из рендерера. Живое DOM-зеркало текущей страницы и панели увеличивается обычной CSS-матрицей. Четыре маскированных краевых сектора отражают и растягивают реальное HTML/SVG-содержимое; отдельный слой рисует тонкий блик. Никакие изображения товаров/интерфейса или заранее записанные видео не используются как источник.
- Центр увеличивается до 1,46× при удержании. Источник привязан к координатам viewport; прокрутка, тема и изменения DOM учитываются. Положение и текущая деформация по-прежнему управляются одним прерываемым requestAnimationFrame в LiquidNavigation.
- Исходная `.nav-glass-material` больше не скрывается из-за ready/available. При ошибке подготовки зеркала линза отключается, а настоящая плашка продолжает работать. Ready устанавливается после построения источника, а не по наличию интерфейсов браузера.
- Без CSS-масок остаётся увеличивающий центральный слой. Reduced motion/forced colors отключают линзу; навигация сохраняется.
- Визуальные копии aria-hidden/inert/pointer-events:none, исходные id и обработчики удаляются, фокусируемые элементы получают tabindex=-1. ID-правила оформления получают локальные data-lens-source-id алиасы; дублирующих id нет. Содержимое зеркала никуда не отправляется.
- Убраны повторные backdrop blur в каждом секторе и копирование сотен вычисленных CSS-деклараций. Чистый источник повторно не строится на каждое нажатие. Наблюдатель, слушатель ввода и ожидающий sync-rAF освобождаются в dispose.
- `web/ui.js`: финальный пункт берётся из координаты pointerup, если последний pointermove был пропущен/объединён браузером. Отмена, preview без перехода и commit по отпусканию сохранены. В покое геометрия/оформление исходных подложек не изменены.
- Импорт модуля содержит версию `?v=dom-optics-v3`, чтобы новый путь не совпадал с прежним URL модуля.

## Проверки и ограничения

31 JS-тест: существующие сценарии приложения, отмена, быстрые переключения, reduced motion; добавлены проверки проекции/увеличения/отражения, сохранения плашки при формально ready, но пустом рендерере, и отпускания без последнего move.

На отдельном стенде с реальным API/тестовой PostgreSQL и имитацией Telegram SDK проверены оба кабинета и доступные разделы, светлая/тёмная темы, native browser drag, синтетический жест с разворотами, отказ источника, отсутствие масок и reduced motion. Проверены ширины 320/390/820 px, отсутствие повторных id/фокуса в копиях, карточка, трекинг и передача тестовой платёжной ссылки. Реальная оплата не проводилась.

В браузере ширина значка выросла с 22 до 32,12 CSS px (32,12/22=1,46). Оптимизированный прогон без видеозахвата: 384 интервала rAF, p50 16,7 мс, p95 17,7 мс, max 17,8 мс, интервалов >33 мс нет. Это замер кадровых вызовов, не presented FPS телефона.

Новая версия внутри Telegram iOS/Android ещё не проверена. CSS-сектора являются приближением оптики: они не воспроизводят непрерывную нативную дисперсию, тонкие отражения и точный профиль краевого преломления оригинала. На границах секторов возможны отличия. В копиях отключён повторный backdrop blur; размытие отличается от финального кадра исходной панели. Canvas/video/iframe/dialog не зеркалируются. Точная копия оригинала не заявляется.

Новые зависимости и миграции не нужны. Запуск — прежний main.py/конфигурация PyCharm. После обновления полностью закройте Mini App и заново откройте его через меню бота: уже открытый документ сохраняет старые загруженные модули.
