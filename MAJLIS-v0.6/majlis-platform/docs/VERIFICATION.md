# Проверка версии 0.6 — 15.10.2026

Основа — 56 исходных файлов 0.5, сверенных по SHA-256. До изменений её полный набор: 65 passed in 6.65s (baseline-v0.5.txt). 001/002 и runtime lock сохранены побайтно.

- Итоговый Python: **87 passed in 7.76s** в отдельной настоящей PostgreSQL, отдельные runtime/migration роли. Все прежние тесты сохранены; добавлены коммерческие правки, платежи/ETA/history, классификация transfer из 0.5, строгий JSON-контракт, безопасный dry-run, атомарный rollback, конкурентные повторы и права import-map.
- Node: **6 passed**, включая сохранение нескольких страниц и фильтров, stale responses, escaping/деньги, принадлежность, неизменность checkpoint-даты после payment/ETA.
- Браузер с mock API/SDK и вымышленными данными: копирование доступно, удаление URL и сохранение товара/120.01 руб. отображаются корректно. Первая отрицательная проверка удаления выявила неверное поле в mock API (url вместо payment_url); после исправления стенда повтор прошёл. Это не проверка Telegram SDK на устройстве и не замена backend-тестов. Скриншот — evidence/ui-reviewed.png.
- Реальный Uvicorn с тестовой PostgreSQL: HTML/JS 200, public ready 403, health-token ready 200, unsigned bootstrap 401, подписанный fictional buyer 200, oversized body 413; security headers есть. Запросы подписаны фиктивным тестовым токеном, не реальным Telegram.
- pg_dump/restore-test: новая отдельная база, **10 таблиц, 31 ограничение**, хеши/структура совпали, **15** проверяемых нарушений CHECK/FK/UNIQUE отклонены. Данные — тестовые, включая synthetic import. ACL намеренно исключены. Рабочая база не восстанавливалась.
- Ruff: ноль замечаний; Bandit с существующими точечными объяснениями nosec: ноль неаннотированных результатов. Это автоматические проверки, не гарантия отсутствия уязвимостей.

Команды/машиночитаемые результаты находятся в evidence пакета отчёта. Исторические проверки 0.5 (зависимости, роли, Compose и аудиторский baseline) отмечены отдельно; не выдаются за новое развертывание.

Не подтверждены: настоящие Telegram-сессии/отправки 0.6, iOS/Android/Windows, рабочие внешние API/платежи, старая схема и миграция заказчика, production HTTPS/ACL/нагрузка, согласованные retention/RPO/RTO.
