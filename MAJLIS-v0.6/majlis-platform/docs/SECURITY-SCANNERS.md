# Классификация статических замечаний

Проверки не отключены целиком. Ruff использует E4/E7/E9/F/I/B/BLE/PLW/UP/SIM; файл pyproject.toml входит в проект. Depends перенесены в Annotated. Неиспользуемые импорты удалены, широкие исключения оставлены только на явно помеченных внешних границах CLI/HTTP/launcher, чтобы не раскрывать реквизиты из исключений.

Bandit B404/B603: локальные пометки стоят у конкретных subprocess-вызовов. Это фиксированные аргументы Python/Docker/SSH, shell не используется, Docker/SSH находятся как абсолютный путь. Остаточный риск подмены исполняемого файла пользователем того же ОС-аккаунта не устраняется приложением. CLI имена БД/контейнера проверяются, SQL identifiers составляются psycopg.sql.

B104: bind 0.0.0.0 нужен внутри контейнера, compose публикует только Caddy 80/443, PostgreSQL/API внешних host-портов не имеют. Локальный main.py запускает API на 127.0.0.1.

B608: значения SQL связаны параметрами, динамические identifiers — psycopg.sql; поля поиска фиксированные. Если Bandit показывает неподтверждённое срабатывание, оно разбирается по строке, а не подавляется для целого файла.

requirements.lock теперь включает официальные SHA-256 файлов PyPI для тех же runtime-версий; установка требует совпадения хешей. Проверка зависимостей Python не заменяет скан Docker/ОС, эксплуатационные тесты и code review. Docker-теги пока не закреплены digest: digest зависит от конкретной архитектуры/поставки; необходимо проверить образ и закрепить его перед серверным релизом, а не записывать непроверенный digest.
