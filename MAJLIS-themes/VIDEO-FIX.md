# Исправление после записи экрана

Источник наблюдения: пользовательская запись «Запись экрана 2026-10-15 в 6.15.22 PM.mov», 35.915 секунды по метаданным AVFoundation. Просмотрены 12 кадров с шагом примерно 2.993 секунды. Это просмотр кадров, а не покадровая проверка всего видео или расшифровка звука.

На отметках около 6–15 секунд переключатель темы имеет фокус, нижнее меню отсутствует. Около 18 секунд после нажатия обновления меню видно. Светлая/тёмная палитры отображаются на записи.

Причина подтверждена кодом: в `web/app.js` обработчики focusin/focusout считали любой select полем ввода. Класс keyboard-open скрывает нижнюю навигацию. Добавленный выбор темы тоже select, поэтому вызывал этот режим. Предыдущая проверка смены значений темы не выявила этот сценарий с реальным фокусом — это пропуск предыдущей проверки.

Исправлены только:

- `web/app.js`: переключатели `[data-theme-select]` исключены из определения режима ввода. Поведение остальных полей сохранено.
- `web/style.css`: отключён системный внешний вид select, добавлена CSS-стрелка; размеры переключателя теперь задаются CSS, а не компактным нативным оформлением macOS.

Проверено на локальном стенде с реальным API/отдельной PostgreSQL и вымышленным Telegram SDK:

- Покупатель: фокус действительно на select после нажатия стрелки с клавиатуры; keyboard-open=false, visibility меню=visible.
- Поиск: при фокусе на поле keyboard-open=true и меню скрывается, как прежде; при переходе к теме keyboard-open=false, меню видно, запрос UI сохранён.
- Менеджер: при фокусе на теме меню видно, все пять кнопок присутствуют.
- Ширина 360 px: переключатель высотой 44 px, горизонтального переполнения нет.
- Синтаксис app.js: Node --check прошёл. Все 17 прежних JavaScript-тестов прошли. Python-тесты повторно не запускались: backend не менялся.

Установлено непосредственно в текущий проект PyCharm. Перезапуск backend не нужен: файлы отдаются с Cache-Control: no-store. Уже открытое окно Mini App нужно закрыть и открыть заново, чтобы загрузился исправленный app.js.

Повторная проверка исправления внутри нативного Telegram не выполнена; результат браузерной проверки не подменяет проверку на устройстве.
