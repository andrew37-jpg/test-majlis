- **17 тестов прошли**: итог `17 passed, 1 warning` взят из pytest. Тесты выполнялись на отдельной базе `majlis_test` с фиктивным Telegram-ключом и фиктивным менеджером, без изменения рабочих прав. Проверены авторизация, изоляция покупателей, строгие суммы, транзакции, конфликт двух редакторов, подписи и повторные события, ограничения ссылок оплаты, очередь и lease, перепривязка клиента, retry/403, ограничитель запросов, миграционные checksum и readiness.
- Сборка Docker-образа `majlis-platform:local-test` завершилась успешно. API-контейнер запущен с read-only filesystem, без capabilities, с no-new-privileges; /health и /ready вернули HTTP 200.
- Чистая установка PostgreSQL в отдельной среде `majlis-initialization-test-v2` создала ограниченную роль приложения; миграции применены из контейнера. Первую неудачную инициализацию исправили включением initdb-скрипта в образ PostgreSQL вместо bind mount.
- Backup pg_dump создан с правами 0600 и восстановлен в отдельную `majlis_restore_test`. После восстановления SQL-запросы вернули 1 миграцию, 1 пользователя, 0 заказов. Рабочая база при восстановлении не перезаписывалась.
- Compose local/server прошли `config --quiet`; синтаксис JavaScript проверен Node, Python — compileall. Локальный браузер без Telegram показывает требование входа через Telegram, демонстрационное переключение ролей отсутствует.
