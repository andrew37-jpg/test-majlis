# Оставшиеся внешние подключения

| Подключение | Реализованная граница | Что получить/проверить |
|---|---|---|
| Telegram | Бот/меню/Mini App, initData, polling/notify | Локальный токен и выбранный HTTPS; реальный тест с согласованным получателем, iOS/Android; BotFather Main Mini App отдельно при необходимости. |
| Карго/checkpoints | HMAC endpoint, event_id/sequence, партия→заказы, монотонность | Документация, sandbox, ID партий и словарь событий/отмен/возвратов. Контракт адаптера и источник sequence. |
| Доставка | Тот же целевой событийный контракт | Подтверждённое название поставщика, трек/order mapping, версии API и sandbox. Слово ASDEC в распознавании не подтверждает CDEK/иной сервис. |
| Сайт | Общий backend для заказов и подготовленный событийный endpoint | Реальный исходник/документация сайта, способ авторизации клиента и связь order IDs; не выдавать Telegram initData пользователям вне Telegram. |
| Оплата | Ручные HTTPS-ссылки, copy/revoke в кабинете, история и очередь | Провайдер, product/invoice ID, создание/отмена, подписи webhook, paid/refund/timeout, sandbox и правила бизнес-оплаты. Ссылка/сумма не означают paid. |
| Старая система | JSON Schema и безопасные inspect/rehearse; приватная mapping-таблица | Реальный старый read-only экспорт и schema, согласованный mapping и cutover. Не использовать прототипную целевую БД вместо старой. |
| Production | Compose, migrator/runtime, Caddy и readiness | Сервер/домен/сертификат, общие лимиты, backup/retention/алерты, скан образов, эксплуатационная нагрузка. |
| Референс | Существующий UI с функциональными улучшениями | Полные утверждённые макеты/пользовательские сценарии для приёмки; скриншоты — лишь ограниченный ориентир. |

Без этих данных нельзя подтвердить реальные адаптеры, оплату или миграцию. Новый проект продолжается на базе v0.5; отдельный новый демонстрационный бот не создаётся.
