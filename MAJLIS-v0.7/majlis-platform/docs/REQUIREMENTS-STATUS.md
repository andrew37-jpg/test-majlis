# Продолжение текущего проекта — состояние до 0.6

Основа: содержимое MAJLIS-PostgreSQL-MiniApp-v0.5.zip, 56 файлов сверены с SHA-256 manifest. Это начатая реализация НОВОГО бота, а не старая система заказчика. Предыдущие локальные 0.3/0.4, их тестовые БД и резервные копии не признаются старой базой заказчика.

Источник пожеланий: автоматическая «Расшифровка собеседования.md», 00:01–02:48. Распознавание не является выверенной стенограммой; ASDEC не считается подтверждённым названием службы. Сайты/мобильные приложения из последующих минут — будущие отдельные продукты, не повод заменять текущий Telegram-проект.
