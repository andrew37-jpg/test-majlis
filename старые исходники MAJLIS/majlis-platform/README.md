# MAJLIS · Telegram Mini App + PostgreSQL

Запуск из Telegram: откройте **[@majlis_test_bot](https://t.me/majlis_test_bot)**, отправьте `/start`, затем нажмите **«Открыть кабинет MAJLIS»** или кнопку меню **«Кабинет MAJLIS»**. Бот должен быть запущен, публичный HTTPS-маршрут — доступен.

## Запуск на настроенном компьютере

В открытом проекте PyCharm используйте **majlis-platform/main.py** и интерпретатор проекта `.venv`. Нажмите Run. Другие копии этого бота должны быть остановлены.

Запуск последовательно поднимает PostgreSQL в Docker, применяет миграции, запускает API, получает временный HTTPS-адрес, проверяет маршрут и настраивает кнопки Telegram. При смене адреса localhost.run меню бота обновляется. **Старые кнопки в уже отправленных сообщениях не меняются:** откройте актуальное меню или отправьте новый `/start`.

Stop останавливает API, туннель и бот. PostgreSQL остаётся запущенным; данные находятся в Docker volume `majlis-local_postgres_data`. Этот режим требует включённого компьютера, Docker и сети. Стабильный домен и круглосуточная работа требуют размещения на сервере.

## Новый компьютер

Требуются Python 3.12, Docker с Compose и OpenSSH. Бесплатный временный туннель использует localhost.run; этот сервис пропускает HTTP-трафик приложения через себя. Для другого размещения предусмотрен `HTTPS_MODE=external`.

Из папки этого проекта:

```sh
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
python -m pip install -r requirements.lock
```

В Windows выберите `.venv\Scripts\python.exe` в PyCharm и установите те же зависимости. Живой запуск этой версии на Windows пока не проверялся.

Скопируйте `.env.example` в `.env`, заполните BOT_TOKEN локально, сгенерируйте разные случайные POSTGRES_ADMIN_PASSWORD и POSTGRES_PASSWORD. Для паролей используйте буквы, цифры, `_` и `-`; пароль приложения повторите в DATABASE_URL. Пример генерации одного значения:

```sh
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

`MANAGER_IDS` по умолчанию пуст: все пользователи — покупатели. Назначение ID даёт доступ ко всем заказам и их изменению; выполняйте это только для согласованного менеджера. Выбранные пользователем роли не принимаются от клиента. Ключи, пароли, сырые initData и базы не входят в архив исходников.

## Структура

```text
main.py                 запуск локальной среды из PyCharm
manage.py               резервная копия и проверка формата архива
majlis/config.py        настройки, секреты, проверки конфигурации
majlis/api.py           FastAPI, авторизация, границы HTTP
majlis/schemas.py       строгие входные модели
majlis/services.py      транзакции заказов, история, аудит
majlis/database.py      пул PostgreSQL и версионные миграции
majlis/bot.py           Bot API, команды, очередь уведомлений
majlis/tunnel.py        HTTPS localhost.run, отслеживание смены URL
majlis/cli.py           отдельные процессы API / bot / migrate
migrations/             неизменяемые SQL-миграции с контрольной суммой
web/                    интерфейс, Telegram SDK, состояния и формы
Dockerfile              контейнер приложения без root
compose.local.yaml      локальная база, порт только 127.0.0.1
compose.server.yaml     PostgreSQL + миграции + API + бот + HTTPS
Caddyfile               HTTPS reverse proxy для своего домена
requirements.lock       проверенные версии Python-зависимостей
```

Подробности: [архитектура](docs/ARCHITECTURE.md), [эксплуатация и сервер](docs/OPERATIONS.md), [результаты проверки](docs/VERIFICATION.md).

## Функциональность и границы

Покупатель: собственные заказы, этапы, даты поставки, история, контакт магазина и каталог, если их адреса настроены. Менеджер: создание, смена этапов, партии и клиента, дата, ручная платёжная ссылка разрешённого сервиса. PostgreSQL: индексированные заказы, пользователи, история, аудит, очередь, события интеграций и курсор Telegram.

Карго, сайт, служба доставки и платёжный провайдер заказчика пока неизвестны. Реальных адаптеров этих сервисов нет. Endpoint интеграций принимает только подписанные события согласованного формата; платёжная ссылка не подтверждает оплату. Словарь этапов доставки нужно утвердить с заказчиком.

Источники протоколов: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [psycopg pools](https://www.psycopg.org/psycopg3/docs/advanced/pool.html), [FastAPI Docker](https://fastapi.tiangolo.com/deployment/docker/), [localhost.run](https://localhost.run/docs/cli/).
